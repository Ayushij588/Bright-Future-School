# Bright Future School — Official Web Application

A premium, international-standard website for **Bright Future School**, Bhopal. Built with React 19, Vite, and React Router DOM v7, adhering to modern UI/UX design tokens with deep Oxford Navy (`#0b1f4b`) and Educational Gold (`#f5b800`).

---

## 🌟 Pages & Structure

1. **Home (`/`)**:
   - Slim top information bar with verified contact details.
   - Professional navigation header with school crest logo and active link states.
   - Hero section featuring campus imagery, admission badges, and primary action buttons.
   - Animated statistics cards (1,500+ Students, 80+ Teachers, 25+ Years, 98% Board Results).
   - Core educational pillars (Why Choose Us).
   - About Us story preview with experience stamp.
   - Academic program cards (Primary to Senior Secondary).
   - Full-width campus facilities showcase (Labs, Library, Sports, CCTV Transport).
   - Interactive photo gallery with category filter and full modal Lightbox.
   - Latest school news and achievement cards.
   - Interactive admission enquiry & campus visit booking form.
   - Comprehensive 4-column footer with school timings and back-to-top navigation.

2. **About Us (`/about`)**:
   - 25-year heritage story in Bhopal.
   - Vision & Mission statements.
   - Core values (Discipline, Curiosity, Respect, Teamwork, Creativity, Lifelong Growth).
   - Why families trust Bright Future School.

3. **Academics (`/academics` & `/programs/:id`)**:
   - Comprehensive curriculum overview following CBSE standards.
   - Academic stages breakdown (Primary, Middle, Secondary, Senior Secondary).
   - Subjects, teaching methodology, and 98% board exam distinction track record.
   - Dedicated deep-dive program pages (`/programs/primary`, `/programs/middle`, `/programs/secondary`, `/programs/senior`).

4. **Activities & Gallery (`/activities-gallery` & `/gallery`)**:
   - Co-curricular sports leagues, performing arts, STEM robotics, and eco clubs.
   - Responsive photo gallery with interactive categories and modal lightbox zoom.

5. **Admissions (`/admissions`)**:
   - Transparent 4-step admission guide.
   - Required document checklist.
   - Transparent fee policy note.
   - Direct helpline details and embedded interactive admission form.

6. **News & Events (`/news` & `/news-events`)**:
   - Category-filtered news articles and notices.
   - Important academic circulars and download lists.
   - Parent helpdesk contact information.

7. **Contact Us (`/contact`)**:
   - Multi-channel contact cards (Address, Phone, Email, Visiting Hours).
   - Admission enquiry & campus tour booking form with instant client-side confirmation.
   - Interactive FAQ accordion for prospective parents.

## 🚀 How to Run & Test Locally

Inside the project directory (`bright-future-school`):

1. **Install Dependencies** (already installed in this repository):
   ```bash
   npm install
   ```

2. **Start the Local Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173/](http://localhost:5173/) in your web browser.

3. **Run Code Quality Lint Checks**:
   ```bash
   npm run lint
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```

5. **Preview the Production Bundle Locally**:
   ```bash
   npm run preview
   ```
